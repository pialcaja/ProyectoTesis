¿Cómo funciona?

  1. Paso 1: Registro o inicio de sesión

    El usuario debe crear una cuenta o iniciar sesión para acceder al servicio.

  2. Paso 2: Selección de tarjeta y monto

    Ingrese el número o código de su tarjeta de transporte, seleccione el monto de recarga disponible y valide sus datos antes de continuar.

  3. Paso 3: Pago y confirmación

    Realice el pago en línea; el sistema procesa la transacción y muestra el estado de la recarga con un resumen que incluye fecha, hora, monto recargado, tarjeta y código de operación.

  • Disponible 24/7
  • Pago seguro
  • Confirmación inmediata
  • Historial de recargas disponible para el usuario
